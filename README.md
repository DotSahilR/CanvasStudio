Final Goal

Build a production-ready React + Tailwind CSS application that feels like an award-winning digital experience. The website should immediately communicate creativity, movement, and community. Keep the current premium aesthetic but make it more refined, more Gen Z, and more immersive. The Classes page must be completely reimagined as an experience-driven discovery page rather than an e-commerce catalog, while the booking flow and custom calendar become standout interactive features that users enjoy using. Every page should include meaningful imagery, polished animations, and smooth transitions, resulting in a fast, responsive, visually stunning website that is ready for deployment without relying on any no-code platform or website builder.

## Development

Prefer working locally? You need Node.js and npm — [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

```sh
git clone <this-repository-url>
cd <repository-name>
npm i
npm run dev
```
